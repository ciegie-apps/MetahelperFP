Die App dient als Client zur Verbindung mit einem Plex Media Server.

3. Verbindung mit Plex

Zur Nutzung der App kann eine Verbindung zu einem Plex Media Server erforderlich sein.

Hierzu kann sich der Nutzer mit einem bereits bestehenden Plex-Konto anmelden oder die Verbindung zu seinem Plex Media Server über die von der App bereitgestellte Anmeldefunktion herstellen.

Im Rahmen der Nutzung werden die für die Verbindung und Authentifizierung erforderlichen Informationen zwischen dem Nutzergerät und den jeweils verwendeten Plex-Diensten bzw. dem Plex Media Server übertragen.

Die Verarbeitung dieser Daten erfolgt niemals auf Servern des Entwicklers der App.

Die App kann Informationen lokal auf dem Gerät des Nutzers speichern, soweit dies für die Nutzung und Aufrechterhaltung der Verbindung erforderlich ist.

Hierzu können insbesondere gehören:

  • Informationen zur Verbindung mit dem Plex Media Server,
  • Authentifizierungsinformationen oder Zugriffstoken,
  • lokale Einstellungen der App,
  • Daten, die technisch erforderlich sind, um die Verbindung mit Plex zu ermöglichen.

Diese Daten werden ausschließlich lokal auf dem Gerät bzw. im lokalen Speicher der von der App verwendeten Anwendungskomponenten gespeichert, soweit dies technisch vorgesehen ist.

Der Entwickler der App erhält keinen Zugriff auf diese lokal gespeicherten Daten.
